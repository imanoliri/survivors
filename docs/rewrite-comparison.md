# Comparison with the existing `rewrite` branch

`origin/rewrite` was reviewed only as comparison. It usefully restored a React shell and broad party/card/building concepts, but its archaeology explicitly had not decoded the binary workbook or rulebook. At its current tip it therefore still includes placeholder cards, provisional values, an abstract 4×3 map, one-step provisional movement, and several invented abstractions.

This branch independently replaces those with exact catalogs/balance, the recovered eight-terrain taxonomy, seeded serialization-safe state, a turn-state flow with order-independent optional activities, weather/card effects, survivor search, five-tile movement, upkeep/endings, the 12×16 generated San Sebastián board, and real-image conversion.

Not carried forward: generic `materials`, warehouse/supermarket/hospital loot POIs, permanent loot depletion, a one-action limit, and generic expeditions that conflate scavengers with attack parties. Those have no authoritative prototype support.

Two duplicate managed-worktree commits (`1da4088`, `b279b34`) were also compared read-only. Their strongest archaeology observations—14×14 versus 12×16 map variants, workshop output choice, adjacent building gathering, information peeking, converter defects, and precise uncertainty boundaries—were reconciled into these documents. Their code was not imported wholesale; conflicts were resolved against the workbook/PDF/source.
